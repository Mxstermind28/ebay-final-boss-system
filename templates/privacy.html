Privacy Policy — eBay Final Boss System

Effective October 14, 2026

eBay Final Boss System is a privately operated application intended for use with the operator's own eBay seller account. For privacy questions, contact ajaniwalsh53@gmail.com.

Information processed

The application researches product and listing information obtained through eBay APIs and stores product research, pricing estimates, and listing status records. If the operator authorizes eBay account access, the application may process eBay authorization credentials and seller account information needed for the requested API functions. The application also uses an authenticated dashboard session.

How information is used

Information is used to operate the private dashboard, research products, review listing information, and, only when separately enabled, interact with the operator's eBay account. Research estimates are not verified supplier costs.

Hosting and service providers

The application is hosted using Railway infrastructure, including its database service, and communicates with eBay APIs. Data processed by these services is subject to their applicable policies. This application is not operated or endorsed by eBay.

Sharing

Information may be transmitted to eBay as needed to perform authorized API requests and processed by the hosting provider to run the application. This application is not intended to sell personal information or offer access to unrelated third-party sellers.

Security

The dashboard requires authentication. Access to application credentials and hosting settings should be restricted to the operator. No internet service can guarantee absolute security.

Retention and deletion

Product research and listing records may remain in the application database until the operator deletes them or the service is retired. The operator can request review or deletion of information associated with this application using the email below. eBay account-deletion notifications are handled through a dedicated notification endpoint; its processing should be reviewed before storing any buyer or other third-party personal data.

Changes

This policy may be updated when the application's features or data practices change. Updates will be posted on this page with a revised effective date.
